Banc d'essais pour écran LCD

Présentation du projet

Ce projet a pour objectif de réaliser un banc d'essais permettant de tester des écrans LCD.

Les écrans proviennent d'un lot donné à l'établissement et leur fonctionnement n'est pas garanti.

 Le banc d'essais permet donc de vérifier rapidement si un écran fonctionne correctement et s'il peut être réutilisé dans des futur projets.


Objectifs

Tester l'affichage de caractères.

Permettre une connexion simple de l'écran au banc d'essais.

Réaliser une procédure de test complète et efficace.

Potentiomètre pour le réglage du contraste

Création du symbole et de l'empreinte de l'écran LCD.

Réalisation du schéma électronique.

Ajout des points de test.

Réalisation du PCB.

Programmation

Le programme de test est développé en langage C avec simulIDE.

La bibliothèque LiquidCrystal est utilisée pour contrôler l'écran LCD.

Le fonctionnement de l'écran utilise le mode 4 bits.

Le lancement du programme de test s'effectue lorsque l'on appuie sur le bouton.

Procédure de test

La procédure permet de vérifier progressivement le fonctionnement de l'écran.
